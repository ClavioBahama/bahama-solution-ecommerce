# bahama-solution-ecommerce

E-commerce Bahama Solution (Next.js/Tailwind).

## Stack

- Next.js
- TypeScript
- Tailwind CSS

## Estrutura

- `app/` — rotas (App Router)
- `components/` — componentes
- `contexts/`, `hooks/`, `lib/`, `models/` — suporte
- `public/` — assets
- `styles/` — estilos
